# helloworld

A collection of creative coding sketches and assets built with [Processing](https://processing.org/).

## Contents

### Sketches

- **flyover_w_perlin_noise/** — 3D terrain flyover animation generated using Perlin noise. Renders a scrolling landscape with triangle strips in P3D mode.

### Assets

- **STEM Acoustics Treatment** — Series of images (1–11 + blank) related to acoustic treatment design.
- **benton1–9** — Benton image series.
- **image1–9** — General image assets.
